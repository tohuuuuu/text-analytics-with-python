# Description

This repo is a fork of [dipanjanS](https://github.com/dipanjanS) (Dipanjan (DJ) Sarkar)'s [book repo](https://github.com/dipanjanS/text-analytics-with-python), adapted to work with Python 3.12, Tensorflow 2 and other current versions of libraries.

# State

* All Jupyter Notebooks except Chapter 10 are updated as described.
* Chapter 10 can't receive an update currently, since it assumes outdated and deprecated versions of tensorflow and tensorflow-hub namely. Adapting that chapter would require a migration to Keras.
* For pinning of certain packages (ipython and scipy), see [requirements.txt](requirements.txt).
